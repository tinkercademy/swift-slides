# Variables Summary

- A variable is something that represents a value. The value can change, so the variable has a name for you to refer to it by.

---

## Declaring Variables:
```swift
var variableName = 0
```

---

## Changing Variables:
```swift
myVariableName = 2
myVariableName = myVariableName + 1
```

---

## Using Variables in Code:
```swift
print(myVariable)
var newVariable = variableName + 11000
```

- Variables that cannot be changed after you declare them are called **constants**:
```swift
let myConstant = 0
```
